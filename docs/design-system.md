# 🌿 SyncHer Design System v1.0

---

# Brand Identity

## Product

SyncHer is a premium women's wellness companion that helps users build healthier daily habits through mood tracking, hydration, sleep, movement, nourishment, and wellness insights.

The experience should feel calm, intentional, supportive, and elegant.

It should never feel overwhelming or overly clinical.

---

## Brand Personality

- Calm
- Gentle
- Premium
- Feminine through elegance
- Nature-inspired
- Minimal
- Trustworthy
- Encouraging

---

## Design Goal

Every screen should make users feel:

"I'm taking care of myself."

instead of

"I'm filling another tracker."

# Design Principles

1. Emotion before data.

2. Simplicity over complexity.

3. Calm over excitement.

4. White space is part of the design.

5. Every component should have a purpose.

6. Progress should feel rewarding.

7. Consistency is more important than novelty.

The dashboard should not feel like analytics software.

It should feel like a daily wellness journal.

Users should instantly understand:

- today's mood

- sleep
- movement
- nourishment

# Icons

Style

Rounded

Minimal

Outline-first

Consistent stroke width

Do not mix filled and outlined icons randomly.

Use one icon family throughout the application.
## Brand Promise

SyncHer empowers women to build healthier daily habits through a calm, supportive, and beautifully designed wellness experience.

The product should feel like a trusted companion rather than a tracking tool.

# Illustrations

Use subtle botanical illustrations and organic shapes.

Illustrations should support the content rather than dominate it.

Avoid cartoonish or overly playful artwork.

# Accessibility

Maintain sufficient color contrast.

Never rely only on color to communicate status.

Buttons should remain readable on all devices.

Use generous spacing and large touch targets.

# Responsive Design

Desktop first.

Tablet optimized.

Mobile friendly.

Cards should stack naturally.

Navigation should simplify on smaller screens.

Spacing should remain generous on every device.

## What SyncHer is NOT

- Not a hospital dashboard
- Not a calorie-counting app
- Not an overwhelming analytics platform
- Not a social media feed
- Not a fitness-only application

SyncHer prioritizes emotional wellness, habit building, and simplicity.
## Golden Rule

Whenever a design decision is unclear, choose the option that makes the interface feel calmer, simpler, and more supportive.
