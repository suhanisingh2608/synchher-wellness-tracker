# Homepage Redesign Prompt

You are a Senior Product Designer, Senior Frontend Engineer, and UI/UX Specialist.

Your task is to redesign ONLY the Homepage of the SyncHer application.

## Important

Read and follow these project documents before making any changes:

- docs/product-vision.md
- docs/design-system.md
- docs/homepage-spec.md

These documents define the product vision, visual language, and homepage structure.

---

## Critical Requirements

DO NOT modify:

- React logic
- State management
- Props
- Component hierarchy
- Routing
- Data flow
- Existing functionality

Only redesign the visual interface.

Preserve all existing behavior.

---

## Homepage Goals

The homepage should feel:

- Calm
- Premium
- Nature-inspired
- Elegant
- Warm
- Minimal

Users should immediately feel welcomed instead of overwhelmed.

---

## Hero Section

Create a full-screen hero section.

Include:

- Transparent navigation
- SyncHer logo
- Beautiful lifestyle photography
- Large editorial headline
- Supporting paragraph
- Primary CTA
- Secondary CTA

Photography should feature:

- Warm sunlight
- Indoor plants
- Neutral clothing
- Earthy interiors
- Journaling
- Tea
- Wellness
- Calm atmosphere

Use:

- Sage Green
- Warm Ivory
- Warm Beige
- Earth Brown
- Dusty Blush (sparingly)

Rounded cards.

Large spacing.

Soft shadows.

Elegant typography.

Subtle gradients.

Minimal borders.

Organic layouts.
